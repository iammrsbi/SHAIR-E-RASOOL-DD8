# शायर-ए-रसूल — Digital Delay DD-8

A fresh Flutter Android project scaffold for the Shair-e-Rasool app.

## Build
The GitHub Actions workflow generates the Android platform folder, runs Flutter analysis, builds a release APK, and uploads it as an artifact.

## Important
This starter includes the initial interface and interactive UI controls. Real-time microphone processing, audio file import/export, delay DSP, compressor, reverb, noise reduction, and WhatsApp sharing still need to be implemented and tested with native Android audio components before this can be considered a finished audio-effects app.
